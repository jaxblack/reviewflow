00 / How to read

决策级别

标记含义变更要求
CONFIRMED来自明确业务不变量，当前必须成立变更前必须修改规格、实现和测试
ASSUMPTION需求没有唯一答案，MVP 已选择默认行为产品确认后可改，但必须记录迁移影响
IMPLEMENTED当前服务端和数据库已有强制行为不能只改页面文案或按钮
OUT OF SCOPE当前明确不实现加入范围前先补状态和审计语义
OPEN生产化前仍需业务或安全负责人决定不得默认为已解决
优先级：当默认假设与明确不变量冲突时，以不变量为准；当页面状态与服务端事务结果冲突时，以服务端和数据库事实为准。

I-07内容作者查看自己的草稿、拒绝稿和历史始终可见自己的工作副本与全部轮次。作者权限
I-08合法 REVIEWER 查看当前 OPEN 内容可见已提交快照、当前进度和允许查看的历史。审核工作区
I-09审核人查看已拒绝但作者正在修改的内容只能看到最近一次已提交快照，不能看到未重提的工作副本。工作副本隔离测试
I-10曾参与审核者查看已关闭内容保留追溯权限，可查看参与过的内容和历史。参与者权限

I-12切换用户时旧身份数据仍在页面先清空列表和详情，再加载新身份工作区，避免短暂泄漏。统一工作区实现
I-13前端 capability 显示可操作，但状态已变化写接口重新读取身份和数据库状态；前端 capability 不可信。服务端二次校验
I-14会话不存在、签名无效或用户已不存在不回退到客户端身份，拒绝当前请求。401 INVALID_SESSION
I-15具有 SUBMITTER 但编辑或提交他人内容角色通过后仍校验作者 ID。403 AUTHOR_REQUIRED

ID场景预期行为结果
S-01标题或正文为空白Schema 和数据库约束共同拒绝。400，不写入
S-02编辑 DRAFT 或 REJECTED作者且拥有 SUBMITTER 时允许，版本递增。成功
S-03编辑 IN_REVIEW 或 APPROVED服务端拒绝，不依赖按钮禁用。409 INVALID_STATE
S-04使用旧 expectedVersion 编辑或提交拒绝过期写入，防止多标签页覆盖。409 STALE_VERSION
S-05旧标签页在内容重新变为可编辑后写入即使状态再次为 REJECTED，版本不匹配仍拒绝。旧版本冲突测试
S-06编辑与提交同时发生最终只接受一个有效版本；另一请求因锁或版本冲突失败。无审核中内容被覆盖
S-07提交 DRAFT同事务创建不可变 revision 和新 OPEN round，内容进入 IN_REVIEW。原子提交
S-08重新提交 REJECTED创建新 revision 和新 round；旧轮决定不参与新轮计票。进度从 0 开始
S-09同一内容并发重复提交行锁、版本和“最多一个 OPEN round”约束阻止重复轮次。一个成功或幂等重放
S-10在 REJECTED 修改 LOW/HIGH允许；下一轮冻结新风险和对应阈值。旧轮规则不变
S-11直接重新提交但没有修改字段MVP 允许，仍产生新轮次。ASSUMPTION
S-12APPROVED 后重新打开或重提当前不允许，APPROVED 为终态。OUT OF SCOPE
S-13删除、撤回或申诉当前没有状态和 API，不做隐式软删除。OUT OF SCOPE
S-14提交事务在快照后中途失败revision、round、content 和 idempotency 全部回滚。故障回滚测试
S-15公网持续创建用户、内容或审核轮次达到用户、内容或每内容轮次硬配额后，事务拒绝且不新增任何记录。507 CAPACITY_LIMIT_REACHED

04 / Review and concurrency

审核决定、幂等与竞争边界

ID场景预期行为错误或终态
R-01LOW 第一位合法审核人通过一票达到阈值，轮次和内容同时通过。APPROVED 1/1
R-02HIGH 第一位审核人通过记录决定但保持 OPEN，内容仍在审核中。IN_REVIEW 1/2
R-03HIGH 同一审核人尝试提供第二票不能计为第二位；相同决定返回原记录，冲突决定返回 409。进度仍为 1/2
R-04HIGH 第二位不同审核人通过达到阈值，轮次和内容同时通过。APPROVED 2/2
R-05LOW/HIGH 任意合法审核人拒绝立即结束当前 OPEN 轮次。REJECTED
R-06拒绝理由为 null、空串或纯空白拒绝决定不会落库。422 REJECTION_REASON_REQUIRED
R-07通过意见为空允许，comment 保存为 null。成功
R-08HIGH 先通过、后拒绝两条决定均保留，轮次唯一终态为 REJECTED。合法历史
R-09轮次关闭后新的审核人继续决定不写入失败方决定。409 ROUND_CLOSED
R-10同一 key、相同请求重试返回第一次保存的状态码和响应体。Idempotency-Replayed
R-11同一 key、不同请求体防止把一个 key 用于两个业务动作。409 IDEMPOTENCY_KEY_REUSED
R-12新 key、同一审核人、相同决定和意见返回既有决定，不新增记录。一条 decision
R-13新 key、同一审核人、不同决定或意见决定不可修改。409 ALREADY_DECIDED
R-14终审通过与拒绝并发先进入写事务者获胜，失败请求完整回滚。唯一 APPROVED 或 REJECTED
R-15HIGH 两位不同审核人同时通过写事务串行，第一票保持 OPEN，第二票关闭为 APPROVED。两条决定，一个终态
R-16业务提交成功但 HTTP 响应丢失客户端复用 key 后读取原响应，不重复执行业务写入。幂等恢复
R-17业务事务失败并回滚幂等记录一起回滚，后续重试可重新执行。无半成功状态
R-18写请求缺少 key，或 key 长度不在 8–100 字符业务事务开始前拒绝请求。400 IDEMPOTENCY_KEY_REQUIRED
R-19同一代理来源跨多个写接口持续请求会话切换、内容和管理写接口共享每分钟额度。429 RATE_LIMITED

06 / Product and operations

仍需确认或生产化的边界

ID主题MVP 行为生产化前需决定
Q-01资源不可见错误返回 403 CONTENT_NOT_VISIBLE。是否统一返回 404 以降低枚举风险。
Q-02审核分配与负载公共待审池，无负责人。是否需要指派、抢单、转派、回避和负载均衡。
Q-03盲审规则审核人可见进度和历史。是否隐藏其他审核人的决定，避免相互影响。
Q-04重提条件不要求实际修改。是否要求字段变化、填写修订说明或回应拒绝理由。
Q-05幂等记录保留期持续保存在数据库。保留时长、清理任务和审计留存要求。
Q-06列表规模MVP 返回完整结果并在前端筛选。游标分页、服务端筛选、稳定排序和容量上限。
Q-07真实身份系统公开 Demo 使用预置用户切换。接入组织身份、角色同步、会话失效和操作追责。
Q-08通知和时限不发送通知，不计算 SLA。提醒、催办、超时升级、代理审核和节假日日历。
Q-09删除、撤回、申诉均不支持。状态机、权限、审计、数据保留和恢复语义。
Q-10富文本与附件纯文本正文，无附件。HTML 清洗、附件扫描、版本快照和下载授权。
Q-11多实例部署SQLite WAL 单实例。迁移 PostgreSQL、行锁、连接池和跨实例并发测试。
Q-12备份与恢复目标发布前人工备份。RPO、RTO、定时备份、加密、保留周期和恢复演练。
变更流程：确认任一 OPEN 项后，先更新本页和系统设计，再修改服务端状态机或权限，补齐自动化测试，最后重新生成 HTML 并发布。
