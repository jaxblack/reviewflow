05 / Limitations

尚未纳入当前门禁

以下项目属于生产化测试蓝图，不应从当前 PASS 结论中推导为已经完成。
  • 真实 PostgreSQL + Testcontainers 的约束、部分索引与行锁测试。

  • 在决定写入后、状态更新后等位置进行故障注入并验证完整回滚。
  • 持续集成环境中的全流程 Playwright 测试与可访问性扫描。
  • 容量、压力、备份恢复时长和多实例高可用验证。
